# Max Profit Problem – Python

##  Description
This project solves the Max Profit Problem using Python. It finds the best combination of Theatres, Pubs, and Commercial Parks to maximize earnings within a given time.

##  Building Details

| Building | Construction Time | Earnings per Unit of Operational Time |
|---|---:|---:|
| Theatre (T) | 5 units | $1500 |
| Pub (P) | 4 units | $1000 |
| Commercial Park (C) | 10 units | $2000 |

##  Concepts Used
- Python
- Dynamic Programming
- Optimization

##  How to Run

1. Clone this repository.
2. Open the project in your Python editor.
3. Run the Python file:

```bash
python max_profit.py
```

## Test Cases

##  Output
The program displays the maximum earnings and the number of each building developed.

Example:

```text
Earnings: $16500
T: 2 P: 0 C: 0
```

## 🎯 Objective
To maximize profit by choosing the optimal combination of buildings within the given time constraint.
